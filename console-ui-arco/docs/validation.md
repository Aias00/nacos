# 验证范围与结果

本文保留可复核的范围与结果，不包含部署凭据、内部主机地址、业务配置内容或数据库备份。

## 同机三节点验证（2026-11-13 UTC）

环境为修改版 Nacos 3.3.0、三个独立 Java 17 进程、独立目录与端口、一个独立 MySQL 数据库。
SDK 使用业务依赖中的 Nacos 2.2.3，在 Java 8 上执行。

- 三个节点互相识别为 UP，同一测试 token 可访问三个节点，匿名配置请求被拒绝。
- 从三个节点分别写入配置，其他节点最终读到相同内容，跨节点监听收到更新。
- 临时实例可从三节点发现；持久实例通过 v3 Admin API 验证 Raft 复制。
- 将持久实例组 Leader 转移到待停止节点，实际停止该节点后，两节点重新选主并继续读写。
- 确认原连接指向被停止节点的 SDK 自动重连、重注册，并接收后续配置更新。
- 节点恢复后补齐数据，注销与删除最终收敛；测试进程、数据库和用户已清理。

该验证不能证明跨主机容灾、网络分区、数据库高可用或容量。故障后远端临时 client 副本可能
按默认 `nacos.naming.client.expired.time=180000` 在约三分钟的窗口内清理。
持久实例注册验证使用 v3 Admin API，没有把 SDK 2.2.3 的旧 HTTP 持久注册路径声明为已验证。
